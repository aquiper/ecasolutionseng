Client tools

Calculations that sit next to the work

Three tools used in support of MIC, HIC fitness-for-service, and weld / HAZ decisions. Access is issued to clients; they are not public calculators.

01

MIC Risk Evaluator

A client-access tool for microbiologically influenced corrosion risk. Used where water chemistry, operations, and materials decisions have to be argued together.

About this tool

02

HIC FFS Tool

Coupon-to-pipe HIC assessment on EFC 16 / API 579 / BS 7910, including FAD, population screening, and a reliability check. Issued as a client dashboard.

About this tool

03

Steel Chemistry / HAZ Toughness Predictor

Estimates HAZ toughness from steel chemistry to support welding procedure and material decisions before a procedure is locked.

About this tool
