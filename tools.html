Tools

Engineering tools for project decisions.

Five tools support corrosion, materials, and fitness-for-service assessments. Access and demonstrations are available to clients as part of an engagement, with the inputs, assumptions, and use defined for the project.

Client application

MIC Risk Evaluator

The MIC Risk Evaluator brings together water chemistry, operating conditions, materials, and evidence of possible microbial activity to support an assessment of microbiologically influenced corrosion.

Project use: Assess MIC risk for the pipeline or facility under review using the available operating and materials information.

A client web application with login access. Demonstrations are available during an engagement.

Request access

Client application

HIC FFS Tool

The HIC FFS Tool connects hydrogen-induced cracking results from test coupons to a pipe fitness-for-service assessment. It uses the EFC 16 / API 579 / BS 7910 framework, including the Fu & Fang fracture-mechanics criterion.

Project use: Evaluate an individual flaw or a population of flaws and examine reliability through Monte Carlo analysis, which samples a range of input values.

A client dashboard for sour-service and HIC assessments. Access is issued with the engagement.

Request access

Client application

Steel Chemistry / HAZ Toughness Predictor

The predictor estimates heat-affected zone (HAZ) toughness from steel chemistry to support early review of materials and welding procedures.

Project use: Screen chemistry-dependent toughness estimates before finalizing a welding procedure or accepting a mill heat.

It is a decision-support estimate, not a substitute for qualification testing or production impact tests. Access is provided to clients.

Request access

Client application

ECA / FAD Tool

A Level 2 fitness-for-service and engineering critical assessment tool using BS 7910 and API 579 Part 9.

Project use: Review a failure assessment diagram (FAD), a probabilistic assessment, and a Level 3 tearing screen to support a documented evaluation of a flaw.

A client dashboard for fracture and fitness-for-service work. Access is issued with the engagement.

Request access

Client application

Dense-Phase CO2 Pipeline Tool

A tool for dense-phase CO2 pipeline materials and integrity assessments using DNV-RP-F104 and incorporating a pre-commissioning MIC corrosion allowance.

Project use: Evaluate wall thickness and grade alongside fracture-control and decompression considerations for CCUS transport.

A client desktop tool. Access is issued with the engagement.
